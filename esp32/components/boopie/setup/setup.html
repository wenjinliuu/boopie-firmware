Wi-Fi

AI 助手

没选就是 Muse。Muse 需要开发者 token、App 配对和海外网络；网络不方便时可以用小智，国内服务器，不用 VPN。

怎样接入小智
  1. 这里选“小智”，并让板子连上 Wi-Fi。
  2. 板子的 设置 › AI 助手 › 小智接入 会显示一个 6 位激活码。
  3. 手机浏览器打开 xiaozhi.me，登录控制台。
  4. 添加设备，输入激活码。
  5. 绑定一次就好，就能直接对布比说话。

Muse

开发者 token 在哪里拿
  1. 浏览器打开 gadgets.muse.ai，用你的 Muse 账号登录。
  2. 点 Account › SDK tokens，生成一个 token。
  3. 复制那串 mgst_ 开头的字符，粘贴到上面，保存。

每个人用自己账号的 token。保存后 Boopie 会重启一下。

怎样接入 Muse
  1. 先填好上面的开发者 token。
  2. 板子要能访问海外网络：在下面的 VPN 里导入订阅，再在板子 设置 › VPN 里打开。
  3. 手机装好 Muse App 并登录，打开 设置 › 设备 › 开发者模式。
  4. 设置 › 设备 › 右上角 + 添加设备，选板子的名字（板子 设置 › 蓝牙 里能看到）。
  5. 板子屏幕提示时，按一下板子上面的键确认。配对是自动的，设备 token 会自己拿到，不用填。

VPN

支持 Shadowsocks（ss）节点：在机场后台复制订阅时，选「通用 / V2rayN」或「Clash」格式都可以；vmess、vless、trojan 节点用不了。保存后板子自动更新、测速，并选一个能连上的节点。如果板子下载订阅失败，可以用手机浏览器打开订阅链接，全选复制页面内容，粘贴到上面。

存好会自动打开 VPN；在板子 设置 › VPN 里可以换节点。只有 Muse 走 VPN，小智直连。
