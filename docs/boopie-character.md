# 形象设定

Boopie 的屏幕形象全部对齐 Muse 官方固件的**微像素风格**，和官方默认形象并存，在设置里切换。这一页记录敲定的设计和固件里的实现。

预览由 `tools/boopie/avatar_proto.py` 生成，规格和官方像素形象相同：64×64 网格，在 1.75C 上放大 5 倍到 320×320。固件里的绘制代码会照着这个原型移植成 C。

```sh
python3 tools/boopie/avatar_proto.py --out previews/                                     # 全部角色
python3 tools/boopie/avatar_proto.py --out previews/ --character boopie --color 7fe3c4   # 薄荷绿布比
```

输出每个角色每个表情一个 GIF，加上 `all.gif`、`sheet.png`，以及全家福 `family.gif` / `family.png`。

## 一、画风：对齐官方

和官方 `muse_pixel` 一样是**实时程序绘制**，不存图片：

- 64×64 网格 ×5 = 320px，与官方同一个位置、同一套界面
- 有序抖动（Bayer 4×4）做明暗，边缘一圈轮廓光
- 身后一团随状态变色的光晕，周围环绕的小星光，脚下阴影
- 聆听、说话时外圈出现点状圆环
- 整屏配色跟着状态变（沿用官方 SCHEMES 的状态色）

因此**不需要额外的资源分区，也不做“导入形象包”**，固件大小基本不变。

## 二、角色阵容（7 个）

| 角色 | 造型 | 状态灯 | 说明 |
|---|---|---|---|
| Muse | 官方默认角色，胖乎乎，头和身体一样宽 | 官方原样 | **基调不动**，只补上我们多出来的表情 |
| 布比 Boopie | 圆团子，一根偏右歪的触角，顶端光球；小圆手、小圆脚 | 触角光球 | 身体颜色可任意换，默认樱花粉 `#ff9ec8` |
| GPT | 白色圆团子（布比的身形和脸），头顶右侧别一朵 OpenAI 结形标志，像发夹 | 结的位置 | 黑白配色 |
| Codex | 蓝色云朵头小机器人，脸是终端屏幕，眼睛是提示符 `>_` | 屏幕字符 | 光标会闪，说话时光标随声音变长 |
| 小克 | 亮橙色方块，方眼、两侧短手、四条小腿（Claude Code 吉祥物风格） | — | `#f28c5e` |
| DeepSeek 小鲸鱼 | 圆滚滚的蓝鲸，白肚皮，翘尾巴 | 头顶喷水 | 喷水颜色就是状态色 |
| 豆包 | 标志性的大头和波波头，配小身子、小手、小脚 | 发夹 | — |

所有角色共用一套表情引擎：表情决定身体怎么动、眼睛嘴巴的样子、手放在哪、周围的特效和状态灯颜色；角色只负责画自己的身体和脸。

**版权**：官方 Muse 角色（Jollybot）是 Meta 的，GPT、Codex、小克、小鲸鱼、豆包取材于各家品牌，这些都**只限自用**；送人或售卖的固件编译时只保留布比。Codex 官方的精灵图和 OpenAI 的标志原图都不进仓库，原型里只有一张 16×16 的结形点阵。

## 三、表情（13 个 + 叠加层）

编号将与 `components/boopie/boopie_expr.h` 一致。前 7 个顺序和官方 `muse_mode_t` 相同。

### 核心 8 个（覆盖官方固件全部状态）

| 表情 | 样子 |
|---|---|
| 开机 boot | 从一个小点弹出来，先闭眼再睁眼，两颗星星 |
| 待机 idle | 轻微呼吸，每 3 秒眨眼，状态灯慢慢呼吸 |
| 聆听 listening | 睁大眼，一只手举到耳边，蓝光跟着声音闪，点状圆环 |
| 思考 thinking | 看向左上方、托腮，紫光，“…” 一个个冒出来；**持续几秒后变成“工作中”**：掏出小笔记本敲键盘 |
| 说话 speaking | 嘴跟着声音开合，手比划，绿光，音符 |
| 出错 error | 担心的眉毛、波浪嘴，红光闪，汗滴 |
| 关机 off | 挥手再见，慢慢塌下去，画面渐暗 |
| 开心 happy（被戳） | ^ ^ 张嘴，压扁再弹起，双手举起，爱心 |

### 宠物 5 个

| 表情 | 样子 | 角色没画时退回 |
|---|---|---|
| 饿了 hungry | 看向想象泡泡里的一碗饭，捂肚子，橙光 | 待机 |
| 吃东西 eating | ^ ^ 嚼饼干，饼干屑掉下来 | 开心 |
| 犯困 sleepy | 闭眼一鼓一缩，Zzz 往上飘 | 关机 |
| 难过 sad | 撇嘴，往下沉，眼泪 | 待机 |
| 晕了 dizzy | 蚊香眼，左右摇晃，星星绕头转 | 出错 |

### 叠加层（不单独算表情，盖在任何表情上）

| 类别 | 内容 |
|---|---|
| 反应 | “!” 惊讶、大腮红（害羞）、彩色纸屑（庆祝）、飘爱心 |
| 设备 | 低电量（红色空电池闪烁）、充电中（闪电和上升的光点） |

原先的惊讶、庆祝、害羞、没电了、充电中、工作中 6 个独立表情，分别并进了叠加层或思考。

## 四、颜色与自定义

- 布比的身体颜色可以任意更换：给一个主色，程序自动算出暗部、亮部、高光、描边和状态灯的默认光色（调色板换色，和官方一样不占额外空间）
- 眼睛、腮红、眼泪、特效图标是固定颜色
- 更多自定义走两条路：设置页里的选项（形象、颜色），以及让 Muse 生成代码后通过 OTA 更新

## 宠物养成（`components/boopie/pet/boopie_pet.c`）

| 规则 | 数值 |
|---|---|
| 饿 | 只在白天 8:00–21:00；吃饱 3.5 小时后饿；一天最多饿两次；每天 8:00 算刚吃饱 |
| 喂 | 饿的时候屏幕右下角出现一碗冒热气的饭，**点饭碗**才喂（吃饭动画 + 爱心）；点角色本身还是"戳一下" |
| 难过 | 饿了 3 小时没人喂；21:00 后自动消失，不惩罚 |
| 犯困 | 23:00–7:00 没人理 5 分钟 |
| 关机 | 关机的时间不算，开机后接着养 |
| 没有时钟 | 宠物原地等待，联网对时后继续 |

**经验**（每天有上限）：每天第一次见面 10、喂饭 20（饿了 1 小时内）/ 10、戳 2（上限 20）、对话 5 / 轮（上限 30）、小游戏 5–15 / 局（上限 45）。一般使用每天约 95。

**等级**：升一级要 `80 + 30 × 当前等级`，最多 620；**等级不封顶**，每级送 20 颗星星。一般使用约 3 周 10 级、一个月 11 级、约 2.7 个月 20 级，之后大约一周一级。

**星星**：每天第一次见面 2 颗、升级 20 颗，以后加上小游戏和成就；用来买皮肤。

| 3 | 背景·星空 | 13 | 背景·气泡 |
| 4 | 颜色·天空蓝 | 14 | 配饰·红围巾 |
| 5 | 配饰·蝴蝶结 | 15 | 颜色·珊瑚红 |
| 6 | 背景·萤火 | 16 | 背景·代码雨 |
| 7 | 颜色·柠檬黄 | 17 | 颜色·奶白 |
| 8 | 背景·花瓣 | 18 | 背景·霓虹网格 |
| 9 | 颜色·薰衣草 | 19 | 配饰·生日帽 |
| 10 | 配饰·小皇冠 | 20 | 背景·像素故障 |
| 11 | 背景·飘雪 | | |

设置页"Avatar"顶部显示等级、经验和星星；没解锁的颜色和背景显示需要的等级，点了不生效。命令 `pet.status` 报告这些数值（不提供语音喂食）。测试：`tests/test_boopie_pet.py` 模拟整天、整月。

## 五、固件实现

| 部分 | 文件 |
|---|---|
| 表情与叠加层的编号、退回规则 | `components/boopie/boopie_expr.[ch]` |
| 6 个角色的渲染器（原型的 C 移植） | `components/boopie/avatar/boopie_pixel.[ch]` |
| 形象切换：接管 `muse_pixel_*`，选 Muse 时交给官方渲染器 | `components/boopie/avatar/boopie_avatar.[ch]` |
| 设置页“Avatar”：选角色、选颜色（9 种预设） | `components/muse/muse_settings_ui.c` |
| 远程命令 `display.avatar` | `main/app.c`、`main/noise_control.cpp` |

- 官方 `avatar/muse_pixel.c` 一字未改，编译时把函数改名为 `jolly_pixel_*`
- 选择和每个角色的颜色存在 NVS（命名空间 `boopie`），重启后保留
- 充电、低电量（≤15%）叠加层由电量自动触发
- 宠物表情只在待机时显示；Muse 官方角色暂时按退回规则显示核心表情
- 测试：`test_boopie_pixel.py` 让 C 和 Python 原型画同一帧，逐像素比较；模拟器用 `BOOPIE_AVATAR`、`BOOPIE_COLOUR`、`BOOPIE_PET`、`BOOPIE_OVERLAY` 环境变量截图（`tools/boopie/sim_shots.py`）

`display.avatar` 的参数都可选：`avatar`（角色 id）、`colour`（`RRGGBB` 或 `default`）、`expression`（宠物表情，`idle` 清除）、`reaction`（`surprise`/`blush`/`confetti`/`hearts`，配 `on=false` 关闭）。
