# 布比形象设定

布比是 Boopie 自己的像素形象，和 Muse 官方的默认形象并存，可以在设置里切换。名字来自 boop（戳一下）：头顶触角上的光球就是它的“戳戳按钮”。

预览由 `tools/boopie/avatar_proto.py` 生成，规格和官方像素形象相同：64×64 网格，在 1.75C 上放大到 320×320。固件里的绘制代码会照着这个原型移植成 C。

```sh
python3 tools/boopie/avatar_proto.py --out previews/            # 默认樱花粉
python3 tools/boopie/avatar_proto.py --out previews/ --color 7fe3c4   # 换成薄荷绿
```

输出每个表情一个 GIF，加上 `all.gif`（全部表情的动画）和 `sheet.png`（全部表情的静帧）。

## 一、造型

| 部位 | 设定 |
|---|---|
| 身体 | 圆滚滚的团子，宽 34、高 30 格，不随表情改变基本形状，只做挤压、拉伸和弹跳 |
| 触角 | 一根，从头顶偏右长出，默认向右歪 18°；会摇摆、竖直、耷拉 |
| 光球 | 触角顶端，是布比的**状态灯**，颜色随表情变化（见下表） |
| 手 | 两只小圆手，平时垂在身体两侧；可以举起、挥手、放到身前（托腮、捂脸、拿东西） |
| 脚 | 两只小圆脚；跳起来时收起 |
| 眼睛 | 默认 3×5 的豆豆眼，带一个高光点 |
| 嘴巴 | 默认小猫嘴 “ω” |
| 腮红 | 两颊各一小抹，害羞和开心时变大 |

## 二、颜色

- **身体颜色可以任意更换**：只需给一个主色，程序自动算出暗部、亮部、高光、描边和光球的默认光色。默认是樱花粉 `#ff9ec8`
- 固定颜色、不随主色变：眼睛（深紫黑）、腮红（粉红）、眼泪（浅蓝）、各种特效图标
- **光球状态色**：沿用官方固件的状态配色，看灯就知道布比在做什么

| 状态 | 光球颜色 |
|---|---|
| 待机、庆祝 | 身体自己的光色（庆祝时彩虹循环） |
| 聆听 | 蓝 |
| 思考 | 紫 |
| 说话 | 绿，亮度跟着声音 |
| 出错、没电 | 红，闪烁 |
| 开心、充电 | 黄 |
| 犯困、关机 | 暗，渐灭 |

## 三、表情

编号与 `components/boopie/boopie_expr.h` 一致。“退回”是某个风格还没画这个表情时自动显示的替代表情，像素布比 18 个全部画了，所以不需要退回。

## 四、和官方形象的关系

- 官方默认形象（Jollybot）是 Meta 的角色，Apache 协议不覆盖。自用的固件里保留它，作为可切换的选项；送人、售卖的固件编译时关掉
- 布比和 Jollybot 用同一套绘制接口（`muse_pixel.h`），界面代码不用改
- 官方只有 8 个状态，布比多出的 10 个扩展表情只在布比形象下显示；切到 Jollybot 时按 `boopie_expr` 的退回规则显示
