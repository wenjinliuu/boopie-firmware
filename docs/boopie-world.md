# 布比小世界（小窝）

主屏往下滑，或者点主屏左下角的小房子，就进到宠物的家。画风参照 GBA 时代的宝可梦：平涂的柔和颜色，每个物件都有同色系的深色描边，只有两三层明暗。

## 已做：第一阶段（屋内）

### 画面
- 场景按 156×156 画，放大三倍铺满 466 圆屏；背景只画一次，每帧只合成会动的东西，约每秒 15 帧，只在小窝显示时才画
- 顶部：像素大时钟，下面是星星数
- 宠物说话：头顶深色对话气泡，几秒后消失；平时每十几秒说一句（饿了、困了、早上好、随口闲聊）
- 能点的东西头上有白色提示泡，轻轻上下浮动；夜里画面变暗偏蓝，提示泡不变暗
- 底部三个按钮水平一排：功能、背包、商店（蓝底金边，名字在按钮上方）
- 右下角下键旁有“返回 ↓”小提示：下键先关掉打开的面板，再按回主屏

### 两个房间
| 房间 | 能点的东西 | 做什么 |
|---|---|---|
| 一楼客厅 | 电视 | 选小游戏（四个） |
| | 书架 | 相册、聊天记录 |
| | 收音机 | 白噪音 |
| | 食盆 | 饿了就喂（和主屏喂食同一套）；饿的时候碗是空的 |
| | 楼梯 | 上二楼 |
| | 门口地垫 | 出门（户外下一阶段做，现在宠物会说“外面正在建设”） |
| 二楼卧室 | 床 | 睡觉 / 起床；晚上 10 点后放着不管，它会自己去睡 |
| | 衣柜 | 换装（伙伴、皮肤、颜色、配饰） |
| | 镜子 | 改名字 |
| | 书桌电脑 | 宠物状态：等级、经验、星星、心情 |
| | 楼梯 | 下楼 |

点了东西，宠物先走过去，站一下再用；点地板它就走过去；没人管时自己在屋里溜达；睡着时点别处会把它叫醒。

### 三个按钮
- **功能**：小游戏、白噪音、小花园、相册和聊天记录、换装、设置
- **背包**：星星、小花园收获的作物、拥有的皮肤数（以后放道具）
- **商店**：当前角色的皮肤，点一下看价格，再点一次用星星买；已有的点一下穿上/脱下（以后上架家具和种子）

### 货币
只有**星星**一种：升级、游戏、小花园收获都给星星，商店也用星星买。

### 怎么改美术
场景和家具都由 `tools/boopie/world_art.py` 画出来，生成 `esp32/components/boopie/world/boopie_world_art.c`（一套 172 色调色板、每像素一字节，约 120 KB，编进固件）。改了画法就重新运行它。房间里摆什么、在哪、几级出现、点了做什么，在 `world/boopie_world.c` 开头的表里。
